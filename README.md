# dotgo

[English](README.md) · [فارسی](README.fa.md)

A terminal UI for managing dotfiles across several machines (macOS, Ubuntu, …) in one git repo.
Share some files, keep per-OS or per-host versions of others, and compare them without leaving the terminal.
The look is inspired by [bast.sh](https://bast.sh).

## Features
- **Per-OS / per-host variants** — `.zshrc##os.Darwin`, `.zshrc##os.Linux`, `.zshrc##host.fpc`; one key applies the right one for this machine.
- **Compare** — side-by-side or unified diff between variants, against upstream, or between any two commits.
- **Git without the ceremony** — stage files or single hunks, commit, push, pull (`--rebase --autostash`), discard with preview.
- **Safe by default** — destructive actions preview first and ask `y/n`; credential-looking files ask before staging; overwritten files get a `.dotgo-bak`.
- **Edit in place** — `e` opens the file in `$VISUAL` / `$EDITOR` / `vi`.
- **Multi-machine setup** — `dotgo init` creates the repo on your first machine or joins it from another one, backing up conflicting files.
- **Optional SSH peek** — diff a file against the copy on another machine.
- Works with a **bare repo** (`~/.dotfiles`, the usual dotfiles trick) — no migration needed.

## Install
Download the archive for your OS/CPU from the [latest release](../../releases/latest) (linux/macOS, amd64/arm64), then:

```sh
tar xzf dotgo_*_*.tar.gz && sudo mv dotgo_*/dotgo /usr/local/bin/
```

or build from source (Go 1.24+):

```sh
go install github.com/arian24b/dotgo/cmd/dotgo@latest
```

## Quick start
```sh
# first machine: create a new dotfiles repo (origin is optional)
dotgo init --first --remote git@github.com:YOU/dotfiles.git

# another machine: clone it, back up conflicting files, apply this machine's variants
dotgo init --remote git@github.com:YOU/dotfiles.git

dotgo            # open the UI — press ? for all keys
```
Already have a bare repo at `~/.dotfiles`? Just run `dotgo`.

More in the **[usage guide](docs/USAGE.md)** ([فارسی](docs/USAGE.fa.md)).

## Keys (short list)
| Key | Action | Key | Action |
|---|---|---|---|
| `1`–`6` | tabs | `space` | stage / unstage file |
| `j` `k` | move | `] [` `S` | pick / stage hunk |
| `/` | search | `c` `a` | commit / add new file |
| `e` | edit in `$EDITOR` | `x` | discard (confirm) |
| `s` | side-by-side | `A` | apply this machine's variant |
| `l` `L` `m` | log / mark commit | `p` `P` | push / pull |
| `?` | help | `q` | quit |
